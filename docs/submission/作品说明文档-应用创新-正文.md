## 介绍文档（约1016字）

### 5.1 创意背景
学生备考、课程攻坚与知识工作者持续产出时，常见三类断层：目标过大不知道如何开始；计划拆解后超出可用时间；番茄钟只证明投入了时间，不能证明形成了可检查交付。现有工具多停留在倒计时，或把大模型当成一次性文案生成器，规划、执行与复盘相互割裂。本作品立足鸿蒙赛道应用创新方向，基于 HarmonyOS 构建可安装、可演示的智能专注应用，追求“小而美”和场景实用，并把 AI 深度嵌进可执行闭环，而不是附加一个聊天入口。

### 5.2 核心功能设计
核心设计围绕三条产品能力线展开。其一，规划不过载：用户给出目标、可用时间与截止条件后，系统调用 DeepSeek 生成结构化步骤，先以提案形式展示新增、修改与删除，再由本地引擎计算预计耗时、缓冲与可行度；对空泛目标、超载安排、缺失完成标准等进行质量门拦截，不合格计划不会直接覆盖执行版，必要时自动修复一次。其二，执行真闭环：步骤可一键写入计时器并立即专注，支持沉浸模式、最近任务续摊与“演示 1/1”预设；达到预计番茄后进入交付核验，区分已形成交付、部分完成与阻塞，避免把时间达标误当成任务成功。其三，数据能指导下一步：历史支持检索、补记、修正与导出，复盘可沿用上次评分以降低连续使用摩擦；行动洞察给出高效时段、估时偏差与打断原因，并在适合时一键缩短下一轮专注；统计展示近七日项目投入，让记录服务下一轮决策。

### 5.3 技术实现与可靠性
在鸿蒙能力上，作品使用 ArkUI 声明式界面、Preferences 本地存储、通知与音频反馈，以及应用接续能力，使当前计时、任务与计划可在可信设备间迁移；穿戴协同实验室在无真机阶段用明确标注的模拟数据验证压力恢复与受控计划调整，为后续真实传感器接入保留清晰边界。可靠性方面提供密钥诊断、Token 预算、调用审计、弱网本地应急计划，以及可选本机记住密钥与小改动轻确认，兼顾现场演示稳定与日常使用成本。隐私策略上，默认不持久化 API Key，跨设备快照不携带密钥，导出仅在用户主动触发时生成。

### 5.4 市场前景与价值
市场前景方面，短期可作为个人备考与知识工作的专注助手，降低启动阻力并提升计划可信度；中期可向课程任务模板、学习小组过程管理等教育场景延伸；长期在合规前提下探索深度复盘与个性化节奏服务。相对功能繁杂的通用效率套件，本作品切口更窄、闭环更完整，符合应用创新赛题对技术创新、体验新颖、场景实用及 AI 融合的要求。风险通过模型档位选择、本地审计、用户确认与成本透明加以控制。工程上提供分层源码、自动化测试、说明材料与可运行 HAP，保证评委能够复现与核查。
