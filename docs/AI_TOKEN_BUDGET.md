# DeepSeek Token 预算说明

## 作用

Token 预算是每个 Agent 对话独立的本地调用上限，用来约束生成、调整、质量门自动修复和执行复盘的累计消耗。默认上限为 30000 tokens，可切换为 10000、30000 或 60000。

App 只依据 DeepSeek 响应中的 `usage.total_tokens` 累计消耗：

- 低于 80%：显示预算正常。
- 达到 80%：显示接近上限，但仍允许一次新请求。
- 达到或超过 100%：停止该对话后续 DeepSeek 请求。
- 首版计划质检失败后若预算已用完，不再发起自动修复。

单次请求的最终 Token 只能在响应返回后确定，因此最后一次请求可能略微超过剩余额度；预算会阻止下一次调用。提高预算后可以继续当前对话，新建对话会清零已用量。

## 数据与隐私

预算、累计用量和调用审计随当前对话、历史对话及跨设备接续保存。它们只包含数值和调用结果，不保存 API Key 或完整提示词。该预算是 App 侧保护，不替代 DeepSeek 控制台的账户余额、限额和账单。

自动化测试覆盖健康、80% 预警、达到上限停止、异常用量归一化和累加逻辑。当前项目结果为 `75/75` 通过，且 `assembleHap` 构建通过。
